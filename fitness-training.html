TRAINING
PROTOCOL

The blueprint for strength and aesthetics.

Push Day

Focus: Chest, Shoulders, Triceps

  • Flat Bench Press: 3 sets x 5-8 reps
  • Incline Dumbbell Press: 3 sets x 8-12 reps
  • Overhead Press: 3 sets x 8-12 reps
  • Lateral Raises: 4 sets x 15-20 reps
  • Tricep Pushdowns: 3 sets x 12-15 reps

Pull Day

Focus: Back, Biceps, Rear Delts

  • Weighted Pull-ups: 3 sets x 6-10 reps
  • Barbell Rows: 3 sets x 8-12 reps
  • Lat Pulldowns: 3 sets x 10-15 reps
  • Face Pulls: 4 sets x 15-20 reps
  • Hammer Curls: 3 sets x 10-12 reps
